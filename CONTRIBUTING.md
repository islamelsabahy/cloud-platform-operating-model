# Contributing

1. Use fictional data only.
2. Never publish real company, employee, customer, workload, account/subscription, hostname, IP, network, secret, credential, cost, incident, cloud configuration, security finding, or production architecture data.
3. Never commit credentials, private URLs, billing exports, or production configuration.
4. Require ownership for workloads, costs, recovery, and exceptions.
5. Keep platform patterns auditable and reusable.
6. Add test cases for new governance or reliability logic.
